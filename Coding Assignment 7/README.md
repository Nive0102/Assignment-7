# BadBank Application

## Description / Motivation

BadBank is a simple banking application that helps users understand basic banking transactions. It provides a user-friendly interface to deposit and withdraw money and view the account balance.

## Installation Guidelines

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```
2. Open the project folder:

   ```bash
   cd Coding-Assignment-7
   ```
3. Open `index.html` in a web browser.
